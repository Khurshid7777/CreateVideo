# Silicare: контент для Instagram и Telegram

Рабочая папка по ТЗ «Silicare: подготовка к Claude Code и сценарии Reels». Здесь лежат 7 сценариев Reels, 9 каруселей и 3 стартовых поста Telegram, а также автопроверка текстов, субтитры, сборка роликов из отснятого, база знаний бота, расписание и месячный отчёт. Всё в статусе `draft`. Публикует только владелец, после проверки носителем узбекского.

## Что где

| Задача из ТЗ | Файлы | Проверка |

| Пакеты постов | `posts/*.json` — 9 каруселей из плана стратегии (посты 3, 6, 9 — это Reels 1–3) | Автопроверка, затем носитель узбекского |

## Как работать

Все команды запускаются из корня репозитория.

```bash
pip install -r requirements.txt          # нужен fonttools для проверки шрифта
make silicare-hooks                      # автопроверка перед каждым коммитом
python -m silicare.check                 # ошибки и предупреждения по всем файлам
python -m silicare.check --publish       # правила публикации: что ещё мешает выпуску
python -m silicare.build                 # субтитры и готовые подписи в silicare/build/<id>/
python -m silicare.assemble reel-01-how-to-apply --preview   # черновая сборка без съёмки
python -m silicare.bot "Когда можно начинать?"
python -m silicare.report --month 2026-11 --month-index 1 --instagram export.csv
```

Путь одной публикации:

1. Правите JSON. Автопроверка показывает ошибки (стоп) и предупреждения (что ещё не готово).
2. Носитель проверяет UZ и ставит `reviewed_by_native_uz: true`.
3. Вы проверяете пост и ставите `approved_by_owner: true` и `status: approved`. В `schedule.csv` пишете «утверждено».
4. `python -m silicare.check --publish <файл>` должен дать 0 ошибок.
5. `python -m silicare.build <id>` — подпись в `build/<id>/caption.txt`; для Reels — `python -m silicare.assemble <id>`.
6. Публикуете вручную. Первые две недели — каждый пост (задача 8 ТЗ).

## Правила автопроверки

Каждое из этих нарушений — ошибка, коммит и публикация останавливаются:

- запрещённые фразы: «навсегда», «полностью уберёт», «100%», «единственное средство», «одобрено», «разрешено Минздравом», гарантии, обещание «станет мягче» без «может», «созревает до 12 месяцев», оценка внешности; узбекские аналоги;
- обращение к состоянию зрителя («У вас рана?»);
- цена не в сумах;
- хэштегов меньше 3 или больше 5;
- нет поисковой фразы в первых двух предложениях подписи RU или UZ;
- Silicare в кадре без дисклеймера; нет текста UZ; титр только на одном языке;
- рана, кровь или швы в описании кадра; слово «рана» вне контекста «после заживления» или «не клеить на открытую рану»;
- в роликах про раны (`topic: wound`) показан продукт или нет финала «При сомнениях обратитесь к врачу»;
- статус выше `draft` без проверки носителем и утверждения владельцем;
- для публикации: источник утверждения не уточнён, нет точной цитаты из исследования, дисклеймер не утверждён юристом, в тексте осталась заглушка «…».

Предупреждения: числа в титрах, не подтверждённые `claims`; больше 7 слов на карточку; хэштег вне пула стратегии; шрифт без нужных букв.
