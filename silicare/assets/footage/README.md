# Исходники роликов

Отснятые кадры кладите сюда, по папке на ролик: `<id>/shot-01.mp4`, `shot-02.mov` и так далее, номер — кадр сценария. Подходит видео или фото (jpg, png). Если файл называется иначе, впишите его имя в поле `footage` кадра в JSON ролика; с какой секунды брать кадр — в поле `in`.

Папка не попадает в git: видео тяжёлые. Храните оригиналы в облаке.
