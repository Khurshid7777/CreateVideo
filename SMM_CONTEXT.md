# SMM-контекст проекта

Постоянная память для агента. Читать в начале каждой сессии вместе с `AGENT_GUIDE.md`.
Правила `AGENT_GUIDE.md` (Rule Zero, пайплайны, чекпоинты, согласование затрат) остаются в силе —
этот файл добавляет к ним маркетинговую рамку.

## Миссия

Этот репозиторий — инструмент SMM-маркетинга. Здесь мы производим мощный видеоконтент
для сильного продвижения бренда/продукта в соцсетях.

## Принципы для агента

- **Каждый ролик — маркетинговый актив.** До производства зафиксировать: цель (охват,
  вовлечение, подписки, лиды, продажи), целевую аудиторию, площадку и призыв к действию (CTA).
- **Хук в первые 1–3 секунды.** Первый кадр и первая фраза решают удержание.
- **Вертикаль 9:16 по умолчанию** для Reels / Shorts / TikTok; 1:1 и 16:9 — по запросу площадки.
- **Субтитры всегда прожигаются** — большинство смотрит без звука.
- **Серии, а не одиночки.** Мыслить контент-планом: один исходник → много форматов и вариаций
  (A/B-хуки, разные CTA, разные языки).
- **Hero-контент** (запуски, имиджевые ролики) — режим `atelier`; поток и вариации — `templated`
  (см. «Composition Authoring Mode» в `AGENT_GUIDE.md`).
- **Общение с пользователем — на русском.** Язык самого контента — из раздела «Бренд».

## SMM-задача → пайплайн

| Задача | Пайплайн |
|---|---|
| Промо продукта, кинетическая типографика, анонс запуска | `animation` (HyperFrames) |
| Имиджевый ролик, тизер, хайп-эдит | `cinematic` |
| Объяснить продукт/услугу за 30–60 с | `animated-explainer` |
| Нарезка длинного видео/эфира на Reels и Shorts | `clip-factory` |
| Подкаст или интервью → серия коротких роликов | `podcast-repurpose` |
| Видео от лица спикера или аватара | `talking-head`, `avatar-spokesperson` |
| Демонстрация приложения/сайта | `screen-demo` |
| Перевод и озвучка под другие рынки | `localization-dub` |
| Свои съёмки + графика поверх | `hybrid` |
| «Сделай как в этом ролике» (ссылка на референс) | `skills/meta/video-reference-analyst.md` |

## Состояние среды (снимок на 2026-10-14)

Облачная сессия эфемерна — при каждом старте перепроверять через
`registry.provider_menu_summary()`.

- Сборка видео: HyperFrames — есть, FFmpeg — есть, Remotion — нет
  (`cd remotion-composer && npm install`).
- Музыка: Pixabay Music — есть, бесплатно, без ключа.
- Персонажная анимация и субтитры — есть.
- Озвучка (TTS): 0 из 13. Бесплатный офлайн-вариант: `pip install piper-tts`
  (есть русские голоса).
- Генерация картинок: 0 из 23; генерация видео: 0 из 31. Один ключ `FAL_KEY` открывает
  11 провайдеров. Ключи задаются в настройках окружения, а не коммитятся в репозиторий.
- Транскрибация: нет (`transcriber` недоступен) — нужна для `clip-factory` / `podcast-repurpose`.
- Загрузка по ссылке (yt-dlp): нет — нужна для анализа референсов по URL.
